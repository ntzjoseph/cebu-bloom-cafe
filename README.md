# Cebu Bloom Café — Portfolio Demo

A fictional, static café website made with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — layout and responsive styling
- `script.js` — accessible mobile navigation

## Preview locally
Open `index.html` in a modern web browser. Internet access is required for the Google Fonts and Unsplash photos referenced by the page.

## Before using for a real client
- Replace all fictional business details and sample prices.
- Obtain permission or suitable licenses for all photos, logos, and copy.
- Replace placeholder contact information with verified details.
- Test all links and the site on mobile and desktop.
- Publish using a host suitable for the client's needs and verify HTTPS.
- Do not add collection of personal information without an appropriate, secure plan.

This is a static website and does not include a backend, database, customer login, order processing, or working contact form.
